- 完成一个有明确结论的学习、实现或复现里程碑时，在对应阶段目录新增一篇 `YYYY-MM-DD-主题.md`；不按会话逐条记流水账。未来阶段需要时再建目录。
- 记录开头注明日期和状态，正文使用“目标与结论 / 证据 / 未解决的问题”三个部分。证据尽量链接代码提交、专题文档、实验命令与配置、数据、指标，以及服务器产物位置；未知信息直接写“未记录”。

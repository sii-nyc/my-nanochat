## 记录方式

- 完成一个有明确结论的学习、实现或复现里程碑时，在对应阶段目录新增一篇 `YYYY-MM-DD-主题.md`；不按会话逐条记流水账。未来阶段需要时再建目录。
- 开头注明时间、状态，并用一小段话概括这一阶段。正文以连贯叙述回答：起初要弄清什么，关键工作带来了哪些认识，现在形成了什么判断或成果，后续从哪里接续。小标题随内容调整，不必套用固定模板，也不逐项罗列代码改动。
- 在相关叙述旁给出支持关键判断的数字或链接；末尾集中提供专题文档、实验报告、代码提交及产物位置等资料入口。只记录影响理解或后续工作的局限与待解决问题，不为已完成阶段凑待办；确实缺失的重要信息注明“未记录”。
- 每新增里程碑，同步更新本页的当前状态和索引。已有记录如有更正，注明更正内容和依据。

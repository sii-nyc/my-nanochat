悬停左侧文字片段，右侧高亮对应的 token ID；悬停 ID 可反向查看文字。一个字由多个 token 组成时，以完整字形显示，角标标出 token 数。

使用普通文本编码，不额外添加 BOS 或聊天模板；特殊 token 的名称也按普通文字处理。BPT = UTF-8 字节数 ÷ token 数。悬停 ID 可查看原始字节。
